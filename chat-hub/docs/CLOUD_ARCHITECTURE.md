### 1. 消息中转

| 功能 | 说明 | 加密 |

| 实时消息 | 消息即时中转 | ✅ E2EE |

| 消息回执 | 已发送、已送达、已读 | ❌ |
| 消息撤回 | 支持撤回已发送消息 | ✅ |

## 三、文件系统设计

### 架构模式：类微信架构

```
┌─────────────────────────────────────────────────────────────────┐
│                      文件系统架构                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌─────────────┐                                                │
│  │ 客户端      │  1. 计算文件 hash                              │
│  │ (chat-hub)  │  2. 检查是否已存在（秒传）                      │
│  └──────┬──────┘  3. 分片上传                                   │
│         │                                                       │
│         ▼                                                       │
│  ┌─────────────┐                                                │
│  │ 文件网关    │  - 接收上传请求                                │
│  │ (Gateway)   │  - 生成文件 ID                                 │
│  └──────┬──────┘  - 转发到存储服务                              │
│         │                                                       │
│         ▼                                                       │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐            │
│  │ 元数据服务  │  │ 文件存储    │  │ CDN 加速    │            │
│  │ (MySQL)     │  │ (对象存储)  │  │ (边缘节点)  │            │
│  │             │  │             │  │             │            │
│  │ - 文件ID    │  │ - 原始文件  │  │ - 热点文件  │            │
│  │ - hash      │  │ - 缩略图    │  │ - 就近访问  │            │
│  │ - 大小      │  │ - 分片数据  │  │             │            │
│  │ - 类型      │  │             │  │             │            │
│  │ - 引用计数  │  │             │  │             │            │
│  └─────────────┘  └─────────────┘  └─────────────┘            │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 类微信特性

| 特性 | 说明 |
|------|------|
| **秒传** | 相同文件只存储一份，基于 hash 去重 |
| **分片上传** | 大文件分片，断点续传 |
| **缩略图** | 图片自动生成多尺寸缩略图 |
| **就近下载** | CDN 边缘节点加速 |
| **引用计数** | 文件被多处引用，删除时检查引用 |
| **过期清理** | 无人引用的文件定期清理 |

### 存储策略

```
文件类型        存储方式           保留时间
───────────────────────────────────────────
图片           原图 + 缩略图      永久（有引用）
视频           原视频 + 封面      永久（有引用）
音频           原文件            永久（有引用）
文档           原文件            永久（有引用）
临时文件       原文件            7 天
备份文件       压缩包            30 天
```

```
└─────────────────────────────────────────────────────────────────┘
```

### 同步流程

```
同步到云端:
1. 选择要同步的数据
2. 使用 E2EE 加密（用户密钥）
3. 分片上传
4. 更新同步状态

从云端恢复:
1. 选择要恢复的数据
2. 下载加密数据
3. 使用私钥解密
4. 合并到本地
```

## 五、数据库设计

### 云端数据库表

```sql
-- 用户表
CREATE TABLE cloud_users (
  id TEXT PRIMARY KEY,
  username TEXT UNIQUE NOT NULL,
  email TEXT,
  phone TEXT,
  avatar TEXT,
  status TEXT DEFAULT 'active',
  storage_used INTEGER DEFAULT 0,
  storage_limit INTEGER DEFAULT 10737418240, -- 10GB
  created_at INTEGER,
  last_login INTEGER
);

-- 文件表
CREATE TABLE cloud_files (
  id TEXT PRIMARY KEY,
  hash TEXT UNIQUE NOT NULL,
  filename TEXT,
  mime_type TEXT,
  size INTEGER,
  storage_path TEXT,
  thumbnail_path TEXT,
  reference_count INTEGER DEFAULT 0,
  uploaded_by TEXT,
  created_at INTEGER,
  expires_at INTEGER
);

-- 同步记录表
CREATE TABLE cloud_sync_records (
  id TEXT PRIMARY KEY,
  user_id TEXT NOT NULL,
  data_type TEXT NOT NULL,  -- config/skills/mcp/sessions/media
  sync_action TEXT NOT NULL,  -- upload/download
  encrypted_key TEXT,  -- E2EE 加密的数据密钥
  checksum TEXT,
  size INTEGER,
  status TEXT DEFAULT 'completed',
  created_at INTEGER
);

-- 好友关系表
CREATE TABLE cloud_friendships (
  id TEXT PRIMARY KEY,
  user_id TEXT NOT NULL,
  friend_id TEXT NOT NULL,
  status TEXT DEFAULT 'pending',  -- pending/accepted/blocked
  created_at INTEGER,
  UNIQUE(user_id, friend_id)
);

-- 群聊表
CREATE TABLE cloud_groups (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  avatar TEXT,
  owner_id TEXT NOT NULL,
  max_members INTEGER DEFAULT 500,
  created_at INTEGER
);

-- 群成员表
CREATE TABLE cloud_group_members (
  id TEXT PRIMARY KEY,
  group_id TEXT NOT NULL,
  user_id TEXT NOT NULL,
  role TEXT DEFAULT 'member',  -- owner/admin/member
  joined_at INTEGER,
  UNIQUE(group_id, user_id)
);
```

## 六、API 端点

### 消息相关
```
POST   /api/v2/messages/send        # 发送消息
GET    /api/v2/messages/offline     # 获取离线消息
POST   /api/v2/messages/read        # 标记已读
DELETE /api/v2/messages/:id         # 撤回消息
```

### 文件相关
```
POST   /api/v2/files/upload         # 上传文件
POST   /api/v2/files/upload/init    # 初始化分片上传
POST   /api/v2/files/upload/part    # 上传分片
POST   /api/v2/files/upload/complete # 完成上传
GET    /api/v2/files/download/:id   # 下载文件
DELETE /api/v2/files/:id            # 删除文件
```

### 用户数据同步
```
POST   /api/v2/sync/upload          # 上传同步数据
GET    /api/v2/sync/download        # 下载同步数据
GET    /api/v2/sync/status          # 同步状态
```

### 好友关系
```
POST   /api/v2/friends/request      # 发送好友请求
POST   /api/v2/friends/accept       # 接受好友请求
DELETE /api/v2/friends/:id          # 删除好友
GET    /api/v2/friends              # 好友列表
```

### 群聊
```
POST   /api/v2/groups               # 创建群聊
GET    /api/v2/groups               # 群聊列表
POST   /api/v2/groups/:id/join      # 加入群聊
POST   /api/v2/groups/:id/leave     # 离开群聊
DELETE /api/v2/groups/:id           # 解散群聊
```

### 超级管理员
```
GET    /api/admin/users             # 用户列表
POST   /api/admin/users/:id/ban     # 禁用用户
DELETE /api/admin/users/:id         # 删除用户
GET    /api/admin/stats             # 系统统计
GET    /api/admin/logs              # 系统日志
POST   /api/admin/skills/:id/verify # 认证技能
```

## 八、安全措施

### 数据加密

| 层级 | 加密方式 |
|------|----------|
| 传输层 | TLS 1.3 |
| 消息内容 | E2EE (X25519 + AES-GCM) |
| 文件存储 | AES-256 加密 |
| 数据库 | 透明数据加密 (TDE) |

### 访问控制

- JWT Token 认证
- API 限流
- IP 白名单
- 操作审计日志
