## 三、产品业务闭环

### 3.1 用户旅程

```
注册 → 登录 → 选择 Agent → 发起对话 → 获得回复 → 继续对话 → 保存历史
```

### 3.2 核心业务流

| 流程 | 步骤 | 关键指标 |
|------|------|----------|
| 对话流程 | 用户输入 → Agent 处理 → 返回响应 | 响应时长 P99<2s |
| 消息同步 | 发送 → Relay 广播 → 多端接收 | 同步延迟<100ms |
| 会话管理 | 创建 → 切片存储 → 压缩归档 | 存储效率≥80% |

### 3.3 北极星指标

| 指标 | 目标 | 当前 | 度量方式 |
|------|------|------|----------|
| 次日留存率 | ≥35% | - | DAU(D+1)/DAU(D) |
| 对话完成率 | ≥80% | - | 完成对话数/发起对话数 |
| 用户满意度 | ≥4.0 | - | NPS 评分 |
| 付费转化率 | ≥5% | - | 付费用户/总用户 |

### 3.4 埋点方案

#### 事件定义 (≥50个)

| 事件名 | 类别 | 属性 |
|--------|------|------|
| `user_register` | 用户 | user_id, source |
| `user_login` | 用户 | user_id, device |
| `session_create` | 会话 | session_id, agent_id |
| `message_send` | 消息 | session_id, message_type, token_count |
| `message_receive` | 消息 | session_id, response_time, token_count |
| `agent_select` | Agent | agent_id, user_id |
| `error_occurred` | 错误 | error_code, error_message, stack_trace |
| `page_view` | 页面 | page_name, referrer |
| `button_click` | 交互 | button_id, page_name |
| `search_query` | 搜索 | query, result_count |

#### 漏斗定义 (≥5层)

1. **注册转化漏斗**: 访问首页 → 点击注册 → 填写信息 → 完成注册 → 首次登录
2. **对话转化漏斗**: 选择Agent → 发起对话 → 发送消息 → 获得回复 → 继续对话
3. **付费转化漏斗**: 访问定价页 → 选择套餐 → 填写支付 → 完成支付 → 开通服务

### 3.5 告警配置

| 告警类型 | 阈值 | 通知方式 |
|----------|------|----------|
| 错误率 | >1% | 钉钉 + 邮件 |
| 响应时间 | P99>3s | 钉钉 |
| 服务可用性 | <99.9% | 钉钉 + 邮件 + 短信 |
| 内存使用 | >80% | 钉钉 |
