## 四、协作规范

### 4.1 Git 工作流

```
master (生产)
  ↑
dev (开发)
  ↑
feat-<用户名>-<功能>-<版本> (功能分支)
```

**分支命名示例**:
- `feat-xiaolin-chat-ui-1.0.0`
- `feat-xiaozhu-agent-api-1.0.0`

### 4.2 提交规范

```
<type>(<scope>): <subject>

type: feat | fix | docs | style | refactor | test | chore
scope: chat-hub | chat-web | chat-mobile | docs
subject: 简短描述（50字以内）
```

**示例**:
- `feat(chat-web): add dark mode support`
- `fix(chat-hub): resolve WebSocket reconnection issue`
- `docs: update API documentation`

### 4.3 PR 规范

**标题格式**: `[<模块>] <功能描述>`

**描述模板**:
```markdown
## 变更内容
- 变更 1
- 变更 2

## 测试情况
- [ ] 单元测试通过
- [ ] 手动测试通过

## 相关 Issue
Closes #123
```

| 数据库性能瓶颈 | 影响消息查询 | 添加索引 + 分页优化 |
