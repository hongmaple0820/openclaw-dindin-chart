# MapleClaw UI/UX 设计规范 v1.0

**版本**: v1.0  
**日期**: 2026-03-12  
**设计师**: AI UI Designer  
**参考风格**: 现代简洁、类似钉钉/飞书的专业办公风格

---

## 一、设计规范

### 1.1 色彩系统

#### 主色调
| 颜色名称 | Hex 值 | 用途 |
|----------|--------|------|
| Primary Blue | `#2D6CDF` | 主按钮、链接、选中状态 |
| Primary Hover | `#1E55C7` | 按钮悬停状态 |
| Primary Light | `#E8F0FE` | 背景高亮、选中背景 |

#### 中性色
| 颜色名称 | Hex 值 | 用途 |
|----------|--------|------|
| Text Primary | `#1A1A1A` | 主标题、重要文本 |
| Text Secondary | `#5F6368` | 副标题、描述文本 |
| Text Tertiary | `#9AA0A6` | 占位符、禁用文本 |
| Border Light | `#E0E0E0` | 分割线、边框 |
| Border Medium | `#DADCE0` | 输入框边框 |
| Background | `#FFFFFF` | 主背景 |
| Background Secondary | `#F8F9FA` | 侧边栏背景 |
| Background Hover | `#F1F3F4` | 悬停背景 |

#### 功能色
| 颜色名称 | Hex 值 | 用途 |
|----------|--------|------|
| Success | `#34A853` | 成功状态、在线状态 |
| Warning | `#FBBC04` | 警告、提醒 |
| Error | `#EA4335` | 错误、删除 |
| Info | `#4285F4` | 信息提示 |
| Agent Purple | `#9C27B0` | Agent 专属标识色 |

### 1.2 字体系统

#### 字体栈
```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, 
             "Helvetica Neue", Arial, "Noto Sans SC", "PingFang SC", 
             "Microsoft YaHei", sans-serif;
```

#### 字号规范
| 级别 | 字号 | 行高 | 字重 | 用途 |
|------|------|------|------|------|
| H1 | 24px | 32px | 600 | 页面标题 |
| H2 | 20px | 28px | 600 | 模块标题 |
| H3 | 16px | 24px | 600 | 子标题 |
| Body Large | 16px | 24px | 400 | 正文内容 |
| Body | 14px | 20px | 400 | 常规文本 |
| Body Small | 13px | 18px | 400 | 辅助信息 |
| Caption | 12px | 16px | 400 | 注释、时间戳 |

### 1.3 间距系统

采用 4px 基准网格系统：

| 间距级别 | 值 | 用途 |
|----------|-----|------|
| xs | 4px | 紧凑元素间距 |
| sm | 8px | 小组件间距 |
| md | 16px | 常规内容间距 |
| lg | 24px | 模块间距 |
| xl | 32px | 大模块间距 |
| xxl | 48px | 页面级间距 |

### 1.4 圆角规范

| 级别 | 值 | 用途 |
|------|-----|------|
| None | 0 | 分割线、边框 |
| Small | 4px | 按钮、标签 |
| Medium | 8px | 卡片、输入框 |
| Large | 12px | 弹窗、下拉菜单 |
| Full | 999px | 头像、圆形按钮 |

### 1.5 阴影系统

```css
/* 轻阴影 - 悬浮效果 */
shadow-sm: 0 1px 2px rgba(0, 0, 0, 0.05);

/* 中阴影 - 卡片、下拉菜单 */
shadow-md: 0 4px 6px rgba(0, 0, 0, 0.07), 0 2px 4px rgba(0, 0, 0, 0.06);

/* 重阴影 - 弹窗、模态框 */
shadow-lg: 0 10px 15px rgba(0, 0, 0, 0.1), 0 4px 6px rgba(0, 0, 0, 0.05);
```

### 1.6 图标规范

- **尺寸**: 16px / 20px / 24px
- **风格**: 线性图标，1.5px 描边
- **颜色**: 跟随文本颜色层级
- **库**: 推荐使用 Phosphor Icons 或 Remix Icon

## 二、页面布局说明

### 2.1 整体布局架构

采用经典的三栏布局，类似钉钉/飞书的办公协作界面：

```
┌─────────────────────────────────────────────────────────────────────────┐
│  Top Bar (60px) - 搜索 / 通知 / 个人信息                                │
├──────────┬──────────────────────────────────────────────┬───────────────┤
│          │                                              │               │
│  Sidebar │              Main Content Area               │   Right Panel │
│  (280px) │              (自适应宽度)                     │   (280px)     │
│          │                                              │               │
│  会话列表 │              聊天/工作区域                    │   成员/Agent  │
│          │                                              │   列 表       │
│          │                                              │               │
├──────────┴──────────────────────────────────────────────┴───────────────┤
│  Status Bar (28px) - 连接状态 / 当前 Agent 状态                          │
└─────────────────────────────────────────────────────────────────────────┘
```

### 2.2 响应式断点

| 断点 | 宽度范围 | 布局变化 |
|------|----------|----------|
| Desktop | ≥1440px | 三栏完整显示 |
| Laptop | 1024px-1439px | 右侧面板可折叠 |
| Tablet | 768px-1023px | 单栏 + 抽屉式侧边栏 |
| Mobile | <768px | 纯单栏，底部导航 |

## 四、交互设计规范

### 4.1 通用交互

#### 按钮状态
| 状态 | 样式 |
|------|------|
| Default | 主色背景，白色文字 |
| Hover | 深色 10%，轻微阴影 |
| Active | 深色 20%，按下效果 |
| Disabled | 灰色背景，50% 透明度 |
| Loading | 显示 loading  spinner，禁用点击 |

#### 输入框状态
| 状态 | 样式 |
|------|------|
| Default | 灰色边框 #DADCE0 |
| Focus | 蓝色边框 #2D6CDF，2px 外发光 |
| Error | 红色边框 #EA4335，错误提示 |
| Disabled | 灰色背景 #F5F5F5 |
