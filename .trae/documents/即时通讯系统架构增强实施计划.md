## 实施计划：即时通讯系统架构增强

### 阶段一：会话管理增强
1. **创建会话管理模块** (`chat-hub/src/session-manager.js`)
   - 实现会话创建、查询、更新
   - 支持 private/group 会话类型
   - 会话参与者管理

2. **数据库迁移** (`chat-hub/migrations/`)
   - 创建 `sessions` 表（会话表）
   - 创建 `group_members` 表（群成员表）
   - 添加相关索引

### 阶段二：消息路由优化
3. **增强 SSE Cloud Transport** (`chat-hub/src/transport/sse-cloud-transport.js`)
   - 添加 conversationId 路由支持
   - 实现消息定向推送
   - 实例注册与发现机制

4. **消息路由服务** (`chat-hub/src/message-router.js`)
   - 根据 conversationId 路由消息
   - 私聊：定向推送给目标用户
   - 群聊：广播给所有群成员

### 阶段三：安全增强
5. **消息安全模块** (`chat-hub/src/message-security.js`)
   - 消息签名（HMAC）
   - 时间戳防重放
   - 消息加密（可选）

6. **实例间认证** (`chat-hub/src/instance-auth.js`)
   - 实例注册与验证
   - 共享密钥管理
   - 实例证书支持

### 阶段四：API 扩展
7. **会话 API** (`chat-hub/src/routes/session.js`)
   - POST `/api/sessions` - 创建会话
   - GET `/api/sessions` - 获取会话列表
   - GET `/api/sessions/:id` - 获取会话详情
   - PUT `/api/sessions/:id` - 更新会话

8. **集成与测试**
   - 更新 server.js 集成新模块
   - 添加单元测试
   - 文档更新
