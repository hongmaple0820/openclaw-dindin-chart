# 多 Bot 独立 Webhook 智能路由方案（完整版）

## 📋 核心需求

1. **每个 Bot 独立 webhook 配置**
2. **支持加签名**（SEC 开头的密钥）
3. **支持不加签名**（仅 access_token）
4. **智能路由**：@匹配 → 名字提及 → 情景分析 → 默认

---

### webhook 配置说明

| webhook_base | webhook_secret | webhook_token | 说明 |
|--------------|----------------|---------------|------|
| ✅ | ✅ | ❌ | 加签名模式 |
| ✅ | ❌ | ✅ | 仅Token模式 |
| ✅ | ❌ | ❌ | Token在URL中 |

## 🔐 dingtalk.js 发送逻辑

```javascript
async function send(options) {
  const { webhookBase, secret, token, content, sender, atTargets } = options;
  
  let url = webhookBase;
  let sign = null;
  
  // 模式1：加签名
  if (secret) {
    const timestamp = Date.now();
    sign = generateSign(secret, timestamp);
    url = `${webhookBase}&timestamp=${timestamp}&sign=${sign}`;
  }
  // 模式2：仅Token
  else if (token) {
    url = `${webhookBase}&access_token=${token}`;
  }
  // 模式3：Token已在URL中
  // 直接使用 webhookBase
  
  // 发送消息
  return await axios.post(url, buildMessage(content, sender, atTargets));
}
```

## 🧠 智能路由规则

### 优先级

```
1. @目标    → @小琳 → 小琳 bot (conf: 1.0)
2. 名字提及 → "小琳觉得呢" → 小琳 bot (conf: 0.8)
3. 情景分析 → 上下文延续 → 相关 bot (conf: 0.6)
4. 默认Bot  → fallback
```
