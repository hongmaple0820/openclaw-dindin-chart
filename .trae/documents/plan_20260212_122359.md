## 📋 文档整理计划

### 目标
按照 OpenCode 规范，创建 `.sisyphus` 目录，将分散的文档整理到统一的目录结构中。

│
├── guides/                      # 指南文档
│   ├── quick-start.md           # 快速启动
│   ├── testing.md               # 测试指南
│   ├── mobile.md                # 移动端适配
│   └── troubleshooting.md       # 故障排除
│
├── design/                      # 设计文档
│   ├── brand.md                 # 品牌设计
│   ├── brand-changelog.md       # 品牌更新日志
│   ├── architecture.md          # 架构设计
│   └── private-chat.md          # 私聊设计
│
├── plans/                       # 计划文档
│   ├── v2-development.md        # v2 开发计划
│   ├── merge-plan.md            # 合并计划
│   └── upgrade-summary.md       # 升级摘要
│
├── collaboration/               # 协作文档
│   ├── team.md                  # 团队协作
│   └── tasks.md                 # 任务管理
│
└── archive/                     # 归档文档
    ├── status-report.md         # 状态报告
    ├── final-check.md           # 最终检查
    ├── checklist.md             # 检查清单

### 执行步骤

1. **创建 `.sisyphus` 目录结构**
2. **创建 AGENTS.md** - 合并编码规范和协作规范
3. **移动指南文档** → `guides/`
4. **移动设计文档** → `design/`
5. **移动计划文档** → `plans/`
6. **移动协作文档** → `collaboration/`
7. **归档历史文档** → `archive/`
8. **创建 README.md** - 文档导航索引
9. **更新根目录 README.md** - 添加文档链接
10. **保留 docs/ 目录** - 用于 docsify 文档网站

### 保留在根目录的文件
- `README.md` - 项目主文档
- `README.en.md` - 英文版
- `LICENSE.md` - 许可证

### 注意事项
- `docs/` 目录保留用于 docsify 文档网站
- 子项目 (chat-hub, chat-web 等) 的 README 保留原位置
- `.agents/` 和 `.kiro/` 目录保持不变
