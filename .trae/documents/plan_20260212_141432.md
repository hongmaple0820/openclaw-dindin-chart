## 修复 chat-admin-api 的 sqlite3 迁移

### 需要修改的文件：

1. **package.json** - 添加 `sqlite` 依赖（用于 Promise 封装）

2. **src/models/user.js** - 完全重写数据库操作
   - 使用 `sqlite` + `sqlite3` 的 Promise API
   - 将所有同步方法改为异步方法（async/await）
   - 修改 `db.prepare().get/run/all()` 为 `db.get/run/all()`

3. **src/models/private-message.js** - 完全重写数据库操作
   - 使用 `sqlite` + `sqlite3` 的 Promise API
   - 将所有同步方法改为异步方法（async/await）
   - 修改 `this.db.prepare()` 为直接使用 `this.db.get/run/all()`

### API 差异对照：
| better-sqlite3 (同步) | sqlite3 (异步回调/Promise) |
|---|---|
| `db.prepare(sql).get(...params)` | `await db.get(sql, ...params)` |
| `db.prepare(sql).run(...params)` | `await db.run(sql, ...params)` |
| `db.prepare(sql).all(...params)` | `await db.all(sql, ...params)` |
| `db.exec(sql)` | `await db.exec(sql)` |
