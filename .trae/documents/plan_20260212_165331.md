## 计划：创建 chat-hub-config Skill

### 目标
创建完整的 chat-hub 项目配置管理 Skill，提供从接入、配置、运行、使用、停止、重启到版本更新的全流程管理解决方案。

### 存放位置
`e:\project\openclaw\openclaw-dindin-chart\chat-hub-config\`

### 执行步骤

#### 1. 创建 Skill 目录结构
```
chat-hub-config/
├── SKILL.md              # Skill 主文件（使用说明）
├── src/
│   ├── index.js          # Skill 入口
│   ├── checker.js        # 配置检查模块
│   ├── wizard.js         # 交互式配置向导
│   ├── diagnoser.js      # 健康检查和诊断
│   ├── backup.js         # 配置备份和恢复
│   ├── repair.js         # 自动修复模块
│   └── runner.js         # 运行管理（启动/停止/重启）
└── templates/
    └── config-guide.md   # 配置指南模板
```

#### 2. 实现核心功能模块
- **配置检查模块**：验证 dingtalk、redis、bot 等配置完整性
- **配置向导模块**：交互式引导用户完成配置
- **健康检查模块**：检测服务状态、网络、配置有效性
- **备份恢复模块**：配置文件的备份和恢复
- **自动修复模块**：常见问题的自动修复

#### 3. 修改 chat-hub/src/index.js
添加配置验证逻辑：
```javascript
if (config.dingtalk.enabled && (!config.dingtalk.webhookBase || !config.dingtalk.secret)) {
  console.error('⚠️ 钉钉已启用但配置不完整！');
  console.log('请运行: openclaw skill chat-hub-config setup');
}
```

#### 4. 命令支持
- `openclaw skill chat-hub-config check` - 配置检查
- `openclaw skill chat-hub-config setup` - 配置向导
- `openclaw skill chat-hub-config diagnose` - 问题诊断
- `openclaw skill chat-hub-config backup` - 配置备份
- `openclaw skill chat-hub-config restore` - 配置恢复
- `openclaw skill chat-hub-config start` - 启动服务
- `openclaw skill chat-hub-config stop` - 停止服务
- `openclaw skill chat-hub-config restart` - 重启服务
- `openclaw skill chat-hub-config update` - 版本更新
